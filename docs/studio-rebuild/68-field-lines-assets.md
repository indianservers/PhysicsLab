# Magnetic Field Lines provenance

Original procedural Three.js tray/frame, bipolar bar geometry, compass housings/needles, field-aligned line-segment filings, RK4 traces and direction arrows. The equation, vector map/profile, icons and calculated WebGL fallback use original HTML/SVG. Three.js RoomEnvironment is library code under Three.js licensing. No mockup crops or external apparatus images are used.
