# Logic Gates asset provenance

All gate outlines, invert bubbles, ports, wires, branch dots, LED, source switches, dot grid, timing traces, cursor and subject icons are original native SVG. No raster image, screenshot crop or downloaded component artwork is used. The truth table and controls are HTML/CSS; Boolean formula uses KaTeX. Native SVG preserves scalable schematic geometry and works without WebGL. Each network renders its own actual symbol and wiring.

Reference pixels are used only for offline comparisons. Signal colors, lamp and numeric state derive from the shared event solver. The complete timing trace is the calculated response to the documented test sequence, with a live time cursor. It is not an independent decorative waveform.
