# Coupled Oscillators

- Mockup: `08_oscillations/06_coupled_oscillators.png`
- Route: `/motion/coupled-oscillators`

Implemented two coupled pendulums with animated angle state, coupling strength, mass ratio, and time controls; live angles, beat period, normal frequencies, total energy, governing equation, reset, and challenge dialog. The model computes beat period from the normal-frequency difference and includes damping from coupling strength.

Validation: production build succeeds; direct route load passes; default beat period 10.93 s and normal frequencies 3.13/2.56 rad/s; controls update; all required responsive viewports have no horizontal overflow; screenshot captured at 1536x1024.
