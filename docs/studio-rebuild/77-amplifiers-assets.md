# Amplifiers asset provenance

The breadboard, NPN, resistor bodies/leads, ideal capacitor plates, generator, oscilloscope, bench, cables, support posts and hardware keys are original Three.js meshes. Breadboard holes use instancing. Native LCDs and labels use independently drawn canvas textures; waveforms come from the model. Main scopes, circuit diagram and calculated WebGL fallback are original SVG. UI and equations use HTML/CSS/KaTeX. RoomEnvironment supplies procedural lighting.

No mockup crop, screenshot texture or externally downloaded instrument asset is used. The reference image is used only by offline comparison scripts. Light/dark, zoom, two topologies, timing and all seven hardware actions share live state. Ideal passband components are labelled ideal; no finite capacitance or calibrated part number is claimed.
