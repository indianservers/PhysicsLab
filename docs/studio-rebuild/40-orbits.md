# Orbits

- Mockup: `07_gravitation/04_orbits.png`
- Route: `/motion/orbits`
- Status: VERIFIED

Interactive orbital simulation with Earth, elliptical orbit path, launch altitude, tangential speed, central mass controls, periapsis and apoapsis markers, live orbital period, eccentricity, radius, escape speed, equation, reset, and challenge dialog. Uses Newtonian two-body quantities with `v_c = sqrt(μ/r)` and `T = 2πr/v`.

Validation: production build succeeds; direct route load passes; default period 1.60 h, radius 7021 km, eccentricity 0.019; controls update; all required responsive viewports have no horizontal overflow; screenshot captured at 1536×1024.
