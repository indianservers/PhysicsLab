# Lorentz Force provenance

Original HTML/SVG equations, vector triad, trajectory inset and calculated fallback contain no reference crops. Three.js RoomEnvironment/ArrowHelper are library code under Three.js licensing; helper geometry is cloned for owned cleanup.
