# Electric Current asset provenance

Original procedural Three.js instruments, wire envelope, terminals, leads, supports, ion/electron geometry and native microscopic view. Screen labels are generated canvas textures; UI icons and calculated cross-section/graph/fallback are original SVG/HTML. Three.js RoomEnvironment and RoundedBoxGeometry are library code under Three.js licensing. No reference crops or external raster apparatus assets are used. The former unrelated reflection image is no longer part of this route.
