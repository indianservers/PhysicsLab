# Heat Engines

- Route: `/thermodynamics/heat-engines`
- Mockup: `14_thermodynamics/06_heat_engines.png`
- Implementation: `src/pages/HeatEnginesStudioPage.tsx`, `src/lib/heatEngineStudio.ts`

A hot and cold reservoir drive a live engine model. Hot/cold temperatures and compression ratio update Carnot efficiency, work output, rejected heat, pressure, and volume. Reset, learning modes, and challenge dialog are interactive.

Validation: direct refresh, bounded control updates, reset and challenge interactions, six required viewport sizes, TypeScript check, and production build. No page console errors observed.
