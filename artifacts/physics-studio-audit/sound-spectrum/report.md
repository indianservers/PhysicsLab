Five signal types work: ideal sine; ten-term square, triangle and sawtooth Fourier approximations; and a deterministic digital white-noise approximation. Square has odd 1/n coefficients, triangle alternating odd 1/n², and sawtooth alternating 1/n. Pressure is normalized to a common RMS level at each gain. The finite series are band-limited, so they are not exact discontinuous/infinite-harmonic waveforms. All modeled harmonics remain below the 24 kHz Nyquist frequency over the 20–2000 Hz fundamental range.

Calibration is a simulated ideal microphone pressure, not a measurement of room sound or actual device output. At 0 dB gain, p_rms = 20 µPa × 10^(80.2/20); other gains multiply pressure by 10^(gain/20). SPL = 20 log10(p_rms/20 µPa), so default −6 dB gives 74.2 dB SPL. pFS = √2 times the 0 dB RMS calibration; plots use this peak-pressure reference for dBFS. The signal is floating point and does not model ADC clipping. Gain zero now remains zero; the old `Number(v.gain)||-60` incorrectly changed zero to −60. Wavelength = 343/f and period = 1/f for periodic sources; default λ = .779545 m, T = 2.272727 ms.

THD = 100 sqrt(sum(n>=2, A_n²))/|A_1|. An ideal sine has zero THD and one frequency. The reference labels its source Sine Wave but adds harmonic peaks, nonzero harmonic bars, and THD 2.8%. Its displayed relative harmonic levels (−14,−26,−38,−48 dB) would imply approximately 20.61% THD, not 2.8%. The app retains correct signal-dependent outputs rather than fabricating those illustrative peaks. Finite square/triangle/sawtooth THD uses the actual ten-term series, not an infinite-series limit.

Noise is a deterministic zero-mean, RMS-normalized 8,192-sample digital buffer repeated every 8192/48000 seconds (170.667 ms). FFT uses those samples. Waveform/apparatus linearly interpolate samples for display; this interpolation is not an exact continuous white-noise reconstruction. Noise has a finite buffer repeat period but no meaningful single tonal fundamental, tonal THD or wavelength; the UI says Broadband/No tonal period. Frequency is disabled with an explanation for noise. No unbounded random-process or calibrated continuous reconstruction claim is made.

The FFT is a radix-2 calculation of 8,192 generated pressure samples at 48 kHz, with a Hann window and correct one-sided coherent-gain amplitude normalization (DC/Nyquist exceptions retained). The spectrogram calculates 40 independent 4,096-sample FFT windows across generated t=0…5 s. It is generated analysis, not recorded room audio or a fake repeated bitmap. FFT shows a fixed t=0 record; the moving waveform shows the current physical time. These sources have stationary spectral content. Finite-window leakage/scalloping is real and documented. Axis range includes the first six harmonics up to 12 kHz; the harmonic profile separately shows all ten coefficients. No added noise or illustrative extra peaks are inserted. FFT values below −100 dBFS are clipped to the display floor; spectrogram color mapping spans −90…0 dBFS.

Speaker cone displacement is an explicitly illustrative mapping of instantaneous pressure, and the visible tuning fork is a fundamental reference. There is no speaker electromechanical transfer-function or room-acoustic propagation calculation. Default physical time advances at 2/f seconds per real second so tonal cycles can be resolved visually; the reported frequency and analysis sample rate are unchanged. Experiment exposes physical time scrubbing and real-time/slow playback. Real-time audio-rate motion can alias on a display. The app does not play sound or access a real microphone.
